# 📚 Website Toko Buku Online – BukuRasya

## Laporan UTS Pemrograman Web 1

Website Toko Buku Online merupakan aplikasi berbasis web yang dibuat untuk membantu pengelolaan katalog buku, pemesanan, dan pelacakan pengiriman. Project ini dikembangkan menggunakan HTML, CSS, dan JavaScript dengan konsep Front-End serta data dummy.

---

## 1. Persiapan Project

**Langkah Pengerjaan:**
- Membuat folder utama project.
- Menyiapkan file HTML untuk setiap halaman.
- Membuat folder CSS, JavaScript, dan Assets.
- Menghubungkan file HTML dengan CSS dan JavaScript.

**Penjelasan:** Struktur folder dibuat terpisah agar kode lebih rapi, terorganisir, dan mudah dikembangkan.

---

## 2. Implementasi Halaman Login

**Langkah Pengerjaan:**
- Membuat form input email dan password.
- Menambahkan tombol Login.
- Membuat validasi menggunakan JavaScript.
- Menambahkan modal Lupa Password dan Daftar.

**Penjelasan:** Halaman login digunakan sebagai akses awal pengguna sebelum masuk ke dashboard. Jika data tidak sesuai, sistem akan menampilkan pesan peringatan.
